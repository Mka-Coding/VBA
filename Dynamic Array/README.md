# 📦 VBA Dynamic Arrays  
**Convert your fixed Arrays into Dynamic Arrays**  

---

## 🚀 Features
- **Auto Append** – Automatically append item to Array.  
- **Zero Dependencies** – Works in Excel, Access, Word, PowerPoint VBA 2010+.  

---

## 📥 Installation
1. Download `ArrList.cls`  
2. In VBE: `File > Import File > ArrList.cls`  
3. Add reference: `Tools > References > Microsoft Scripting Runtime`  

*Use Cases*
- Append items to your array seamlessly without having to worry about the size of the array.
- Can clear your array using ArrList.Clear method.
