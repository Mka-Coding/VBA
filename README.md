# VBA
A collection of helpful **VBA modules and tools** for Excel, Word, PowerPoint, and Access.  
This repo is designed to make VBA development easier, modern, and more powerful.

---

## 📂 Contents
Each folder contains a standalone project or utility:

- **VBA JSON - Data Tools**  
  Convert Dictionaries, Collections, and Arrays to JSON, perform deep comparisons, and clone nested structures.

*(More projects will be added over time!)*

---

## ✨ Features
- Zero-dependency VBA modules (just import `.bas` files).
- Works across **Excel, Word, PowerPoint, Access** (2010+).
- Clean, reusable code for everyday automation tasks.
- MIT Licensed — free for personal and commercial use.

---

## 🚀 Installation
1. Download the `.bas` file(s) from the desired folder.
2. In the VBA editor:  
   `File > Import File > <ModuleName>.bas`
3. Add references if required (e.g., **Microsoft Scripting Runtime**).
4. Start using the functions in your project!
